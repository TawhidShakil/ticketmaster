# TicketMaster

TicketMaster is a Flutter-based mobile application developed using Dart, with Firebase, Supabase, and SSLCommerz integration.

## Overview

The project explores mobile application development with Flutter and integrates cloud-based services for authentication and data management, along with payment gateway functionality.

## Tech Stack

* **Framework:** Flutter
* **Language:** Dart
* **Authentication:** Firebase Authentication
* **Backend / Database Services:** Firebase, Supabase
* **Payment Gateway:** SSLCommerz
* **Image Handling:** Image Picker
* **Navigation:** Curved Navigation Bar
* **UI:** Flutter Material Design

## Dependencies

Key packages used in the project include:

* `firebase_core`
* `firebase_auth`
* `supabase_flutter`
* `flutter_sslcommerz`
* `image_picker`
* `curved_navigation_bar`
* `cupertino_icons`

## Getting Started

### Prerequisites

Make sure the following are installed:

* Flutter SDK
* Dart SDK
* Android Studio or Visual Studio Code
* A configured Flutter development environment

### Installation

Clone the repository:

```bash
git clone https://github.com/TawhidShakil/ticketmaster.git
```

Navigate to the project directory:

```bash
cd ticketmaster
```

Install the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Project Configuration

The application uses Firebase and Supabase services. Appropriate project configuration and credentials are required before running all integrated features.

The project also includes SSLCommerz integration for payment processing.

## Assets

Application assets are stored in the `images/` directory and are registered through the Flutter asset configuration.
